# creative-output provenance checklist

Use this before approving AI-assisted visual, audio, video, slide, or design work.

## source and rights

- [ ] Original source assets are listed.
- [ ] Generated takes, prompts, or model/tool outputs are listed where available.
- [ ] Licensing, consent, attribution, privacy, and commercial-use status are
      recorded for every non-original asset.
- [ ] Unknown provenance is marked as unknown, not silently treated as cleared.

## artifact source

- [ ] Final render/export is not the only durable artifact.
- [ ] Script, scene spec, storyboard, component source, caption file, prompt chain,
      or edit notes are preserved.
- [ ] Deterministic finishing steps such as captions, text overlays, crops,
      sequencing, checksums, or exports are reproducible where practical.
- [ ] Thin transcript-only or visual-only source notes are labeled with confidence
      limits before lessons are extracted.

## review lanes

- [ ] Visible quality was reviewed separately from provenance and allowed use.
- [ ] Blind comparisons, if used, are treated only as perceptual tests.
- [ ] Transformation/originality claims are supported by source and edit records.
- [ ] Ethical, legal, market, or consent objections are not collapsed into a single
      quality score.
- [ ] The deployment context and audience are named.

## acceptance

- [ ] Final file opens in the target format.
- [ ] Final artifact has a stable path, revision, checksum, or export receipt.
- [ ] Reviewer, decision, limitations, and unresolved risks are recorded.
- [ ] A fresh operator can find the source, rebuild/revise path, and review notes
      without opening the original hosted session.
