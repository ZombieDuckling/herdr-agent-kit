# AI baseline ratchet checklist

Use this when a model, tool, or automation makes the old task feel too easy. The
answer is usually not to ban the tool or accept the old output faster; it is to
make the new baseline explicit and raise the acceptance surface.

## name the shift

- [ ] The pre-tool baseline is written in plain language.
- [ ] The parts now commoditized are named: drafting, grammar, search,
      summarization, formatting, boilerplate, comparison, calculation, or
      procedural compliance.
- [ ] The workflow states whether tool use is allowed, required, disclosed, or
      prohibited for a specific integrity reason.
- [ ] The old task is not reused as if the capability shift did not happen.

## raise the bar

- [ ] The new accepted output requires at least one higher layer: critique,
      source judgment, originality, domain judgment, tests, threat modeling,
      governance, implementation evidence, taste, or user-fit review.
- [ ] Saved time is assigned to a named reinvestment activity instead of more
      undifferentiated volume.
- [ ] Generic fluent output is explicitly insufficient.
- [ ] Human accountability, ethical judgment, and final acceptance remain named
      where consequences exist.

## evidence

- [ ] The request or rubric shows old baseline, AI-assisted baseline, and raised
      acceptance criteria side by side.
- [ ] The review surface contains receipts for the higher layer: citations,
      test logs, diffs, critique notes, decision rationale, or implementation
      proof.
- [ ] Reviewers can tell which parts were generated, verified, changed, and
      accepted.
- [ ] The change is rerun against representative examples before becoming the
      default workflow.

## reject

Reject the update when it only:

- adds more output volume without harder judgment,
- rewards speed to first draft instead of accepted outcome,
- hides tool use where process integrity matters,
- treats task automation as replacement of responsibility, or
- removes human review from consequential decisions because the mechanical layer
  got cheaper.
