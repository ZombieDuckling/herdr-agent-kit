# durable guidance review checklist

Use before promoting old AI, automation, or workbench advice into shared laws, global skills, or long-lived playbooks.

- [ ] The claim has a source pointer and source/retrieval date.
- [ ] The claim is classified as durable primitive, current tactic, market observation, or unsupported source-limited claim.
- [ ] Tool names, creator names, private project names, accounts, paths, domains, and source-specific identifiers have been removed.
- [ ] The durable primitive is written separately from dated implementation details.
- [ ] Current assumptions were checked: model behavior, interface access, pricing, policy, security boundary, user baseline, and review burden.
- [ ] Unsupported or transcript-thin material is not promoted beyond a source-coverage note.
- [ ] Market observations include scope, date, confidence, and a refresh trigger.
- [ ] The promotion target is appropriate: law, playbook, checklist, template, architecture note, project-local note, or no promotion.
- [ ] The next review trigger is explicit.
- [ ] The final shared text teaches the method without identifying the source incident or operator.
