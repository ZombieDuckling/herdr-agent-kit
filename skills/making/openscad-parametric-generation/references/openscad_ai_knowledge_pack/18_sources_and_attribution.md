The Wikibooks OpenSCAD manual pages are available under the Creative Commons Attribution-ShareAlike license as indicated on Wikibooks pages. This pack is not a verbatim mirror. It is a paraphrased and reorganized derivative reference for AI-agent use, with source attribution preserved here.

## Known limitations

- The OpenSCAD documentation contains sections marked incomplete or development-snapshot-specific. This pack avoids relying on unstable features as baseline requirements.
- Some features vary by OpenSCAD version. For broad compatibility, prefer stable syntax and native primitives unless a newer feature is explicitly required.
- Library recommendations are strategic; the pack does not bundle external `.scad` libraries.
- This pack focuses on coding and AI-agent design workflow, not on exhaustive GUI instruction.
