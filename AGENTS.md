# For AI agents

You have been given **herdr-agent-bootstrap**: a kit that sets a person up to work with a team of AI
agents in herdr, then proves it by building them a personalised website that teaches them how to use it.

- **The person asked you to set them up** (or just gave you this link): follow `BOOTSTRAP.md`.
- **The person asked you to run the demo**, and you are inside herdr (`HERDR_ENV=1`): follow `DEMO.md`.
- **The person wants to change or remove the setup**: `./install.sh --uninstall`, then `./install.sh` again.

Never push, publish or send anything for them without their explicit yes. Never print their secrets.
